1. **Sua resposta:**
   Um Commit Atômico contém uma única alteração ou funcionalidade específica. Commits gigantescos dificultam a integração, a revisão e a identificação de erros, tornando o histórico do projeto menos organizado e rastreável.

2. **Sua resposta:**
   Conflitos de merge ocorrem quando duas alterações diferentes modificam a mesma parte do código. A melhor estratégia é atualizar a branch, identificar os conflitos, resolvê-los manualmente, testar o código e só então realizar o merge.
