# 📝 Módulo 3 & 4: Automação DevOps e CI/CD

Responda às questões abaixo diretamente neste arquivo.

1. **O que é Integração Contínua (CI) e como ela se conecta com gatilhos (triggers) do Git como push e pull_request?**

   *Sua resposta:
Integração Contínua (CI) é a prática de integrar e testar o código frequentemente. Triggers como push e pull_request iniciam automaticamente os testes e outras etapas do processo.*

2. **Qual a função de um "Runner" na execução do GitHub Actions e qual a diferença entre o ambiente de testes/QA e o ambiente de produção na Entrega Contínua (CD)?**

   *O Runner é o ambiente responsável por executar os processos do GitHub Actions, como testes e builds. O ambiente de QA é usado para testar e validar o sistema, enquanto o ambiente de produção é onde a versão final é disponibilizada aos usuários.*
