# 📝 Módulo 2: Perguntas Teóricas (Git & Engenharia de Software)

Responda às questões abaixo diretamente neste arquivo.

1. **O que caracteriza um "Commit Atômico" e por que commits gigantescos dificultam a integração e a rastreabilidade do código?**

   Commit Atômico é uma prática de controle aonde cada commit contém uma única mudança funcional, coesa e completa, que funciona de forma independente. Porque um commit serve pra registrar algo e se você registrar um unico commit tudo vai se "juntar" e se vc salvar de forma independente cada commit irá ficar mais fácil de voltar para oque você quer.


2. **Como ocorrem os conflitos de merge no Git e qual a melhor estratégia para resolvê-los de forma segura antes da integração?**

Quando você tenta juntar duas merge que tem as mesmas informações e estão na mesma linha, para resolver, quando você for juntar vai perguntar qual das duas é a correta, vc seleciona a correta e então será resolvido.
